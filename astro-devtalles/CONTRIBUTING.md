# Contributing to astrocurse-devtalles

Thank you for your interest in contributing to the DevTalles Astro course!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Submit a pull request

## Content Guidelines

### Writing Posts

- **Language**: All content must be in Spanish
- **Audience**: Spanish-speaking developers learning programming
- **Tone**: Educational, accessible, with practical examples
- **Format**: Markdown with frontmatter

### Frontmatter Structure

Every post must include:

```yaml
---
title: Spanish title
date: YYYY-MM-DD
description: Spanish description (1-2 sentences)
author: Author Name
image: '/assets/images/post-XX.png'
tags: [Tag1, Tag2]
---
```

### Image Guidelines

- Place images in `assets/images/`
- Name images to match post: `post-XX.png` for `post-XX.md`
- Use descriptive alt text in Markdown
- Optimize images before committing

### Code Examples

- Include working, runnable code examples
- Use appropriate syntax highlighting
- Add comments in Spanish when helpful
- Test code examples before submitting

## File Naming

- Posts: `post-XX.md` (sequential numbering)
- Images: `post-XX.png` (matching post number)
- Use lowercase, no spaces in filenames

## Commit Messages

Use conventional commits:

```
feat: add new post about React Hooks
fix: correct code example in post-03
docs: update README with setup instructions
```

## Pull Request Process

1. Ensure posts follow the frontmatter structure
2. Verify images are properly named and placed
3. Check that code examples are correct
4. Update any related documentation

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help maintain a welcoming community

## Questions?

Open an issue for questions or suggestions about contributing.
